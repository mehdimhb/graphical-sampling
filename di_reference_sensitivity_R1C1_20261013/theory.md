# Limited theoretical statements relevant to reference sensitivity

Write a complete reference as the hard partition together with its medoids and optimal assignment to the fixed observed sample. The partition matters because it determines which units receive each translation; an unordered medoid set alone is not the full reference used by DI.

**Relabeling invariance.** If cluster labels are permuted and the medoids and matching assignments are permuted consistently, every population unit receives exactly the same translation. Thus the translated population and every density value are unchanged, and DI is unchanged. If the optimal assignment is unique, this consistency follows automatically from permutation of its cost-matrix rows. If assignment optima are tied, consistency must be specified rather than presumed. Tied alternative assignments are distinct choices, not harmless relabeling. The experiment canonicalizes full partitions/medoids, checks assignment gaps, and excludes label-only changes from distinct-reference comparisons.

**A sufficient condition for local equality under the specified box KDE.** Let z_l and z'_l be two translated locations of the same original unit, with the same fixed H. Write w_l=H^-1/2 z_l, w'_l=H^-1/2 z'_l. For any fixed vector a define d=max_l||w_l-w'_l-a||inf. For every pair, the change in its infinity-norm distance is bounded by2d, by the triangle inequality. If gamma=min_(l!=m)| ||w_l-w_m||inf-1 | and2d<gamma, no pair can cross the kernel boundary. Every self-evaluated box count, translated density and therefore DI remains identical. In particular, an exactly common translation cancels in all pairwise differences and preserves self-density. This is a condition on translated geometry and kernel margins, not on clustering objective values. The experiment records the actual margin/deformation and count changes for each compared pair.

**What is not proved.** Neither a scalar entropic OT loss nor a within-cluster sum of squares controls the translated pairwise kernel margins by itself. Ordered refinement, hardening, medoid choice and assignment can change discretely. The manuscript supplies no theorem converting small objective gaps into the sufficient geometric condition above, or into a small DI difference. We make no such claim. Empirical loss-matched reference comparisons are required for the examined population/sample.

**Attribution within a reference comparison.** For two computed reference scores, the exact difference is [(1-eta_b)D_b-(1-eta_a)D_a]+[eta_b sign(D_b)-eta_a sign(D_a)]. This is merely a decomposition of the unchanged DI. When signs differ, the second term exposes aggregation effects so that a large score difference is not attributed entirely to a large change in reference geometry. This task reports that attribution only as needed for Reviewer1 Comment1 and does not propose changing the formula or addressing other comments.
