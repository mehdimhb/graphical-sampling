# Matching-distance historical audit — 17 October 2026

**Supported conclusion:** the traced historical DI matching minimizes the sum of **Euclidean distances**, not squared Euclidean distances. This conclusion comes from historical Git modules, notebook scorer overrides, retained numerical outputs, committed tables, and preserved figure bytes. It does not infer historical computation from today's manuscript or package alone. No simulations, clustering fits, TSP searches, DI evaluations, or rescoring were performed.

## Consequence for interpretation

A theorem proved for the squared assignment objective is not automatically a theorem about this historical Euclidean matching pipeline. The two sums can select different assignments; Euclidean ties can matter as well. This is an implementation/theorem correspondence issue even if both pipelines share the same high-level DI aggregation. No new simulations are needed to establish the objective mismatch. Its effect on specific historical means, signs, figures, or design rankings is **not measured here**, and no blanket claim that every reported row is affected is justified.

Reproduce the evidence extraction and read-only comparisons with `python3 extract_matching.py`, `python3 check_provenance.py`, and `python3 build_history.py` from the repository root, using their full paths under this directory. These scripts read Git blobs/CSV/JSON/figure bytes and write only this evidence directory; they do not execute notebook cells or scientific scorer code.
