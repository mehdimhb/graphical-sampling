# Jupyter Experiments

Important working notebooks:

- `ABC_Vincent.ipynb`: main Vincent/ABC experiment notebook.
- `reciprocal.ipynb`: reciprocal CaDsd extraction/debug notebook.

Generated files are kept in `artifacts/`:

- `*.csv`: exported kernels, inclusion probabilities, omega, rho, and rebuilt matrices.
- `*.rds`: saved R reciprocal extraction objects.

Keep new generated CSV/RDS outputs in `artifacts/` so this directory stays easy to scan.
