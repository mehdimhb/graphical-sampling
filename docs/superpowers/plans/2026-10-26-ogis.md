# OGIS Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add matching-preserving indirect sampling through the package GBFS.

**Architecture:** Independent linked model and initialization in `indirect/`;
optional GBFS hooks select linked neighbors without replacing its search loop.
Reporting and a package-backed notebook expose complete distributions.

**Tech Stack:** Existing NumPy, SciPy, pandas, Matplotlib; pytest and nbclient.

**Spec:** `docs/superpowers/specs/2026-10-26-ogis-design.md`

## Global Constraints

- Preserve existing public APIs and default GBFS behavior.
- Preserve all lambda_ik, both FIP vectors, and n throughout optimization.
- Reject duplicate A/B selection before creating a neighbor.
- Use auxiliary variables only for optimization; no new runtime dependencies.
- Do not change unrelated code, publish or merge.

## Review Focus

- Invalid probabilities, nonbinary links, fractional indices and mutable inputs.
- Certainty units, unequal population sizes, tiny masses and infeasible flows.
- Duplicate endpoints, exchange splitting, aggregation and fixed lambda drift.
- Zero auxiliary baseline, alpha endpoints, independent seeds and small restarts.
- Candidate completeness, export reconstruction and notebook Run-All portability.
